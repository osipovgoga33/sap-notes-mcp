# sap-notes-mcp (Go)

MCP-сервер для Claude: поиск и чтение **SAP Notes и KBA** на портале поддержки
SAP (me.sap.com), включая инструкции исправления и их код для вашего релиза,
файл для SNOTE (.SAR) и PDF.

Один самодостаточный бинарник на Go: без Python, Node, Playwright. Два режима:

| Режим | Как ходит в SAP | Вход | Файлы |
|---|---|---|---|
| `browser` (по умолчанию) | скрипты, которые Claude выполняет во встроенном браузере Claude Desktop | ваш, в этом браузере; пароль нигде не хранится | браузер спрашивает, куда сохранить; PDF через окно печати |
| `chrome` | свой Chrome или Edge в фоне, отдельный профиль | сервер по логину и паролю из конфига; при двухфакторке открывается окно для вас | `.SAR` и настоящий PDF сразу в папку |

## Как устроено

Портал SAP отдаёт данные только настоящему браузеру: программа после одного-двух
запросов получает заглушку. Поэтому в режиме browser сервер в SAP не ходит: каждое действие
возвращает короткий скрипт; Claude выполняет его инструментом JavaScript
встроенного браузера на вкладке me.sap.com, где вы вошли, и получает компактный
JSON.

- Один раз войти на me.sap.com во встроенном браузере. Двухфакторка работает
  как обычно — подтверждаете вы.
- Сессия живёт в профиле браузера: браузер можно закрыть, Claude сам откроет
  вкладку me.sap.com.
- Сессия истекла — скрипт вернёт `login_required`, Claude попросит войти снова.
  Пароль Claude не вводит никогда.
- Запросы по одному, в человеческом темпе. Для массовых выгрузок не годится.

### Режим chrome

Сервер запускает Chrome или Edge (находит сам либо `SAP_NOTES_BROWSER`) с
отдельной папкой профиля и управляет им по протоколу отладки на 127.0.0.1. Там
выполняются те же скрипты, результат возвращается сразу.

- Вход: сервер заполняет форму SAP ID (в один или два шага) из `SAP_USERNAME` /
  `SAP_PASSWORD` и ставит «сохранять регистрацию». Пароль отправляется **не
  больше одного раза за вызов**: форма вернулась — вызов останавливается с
  «rejected». После нескольких неверных паролей SAP блокирует учётку.
- Двухфакторка или пароль не задан: браузер перезапускается видимым окном на
  странице входа, инструмент отвечает `login_window`, вы входите, следующий
  вызов идёт снова в фоне.
- `download` сохраняет `.SAR` (под именем от SAP, например `0003771041_00.SAR`)
  и печатает страницу ноты в `SAP Note <номер> v<версия>.pdf`.
- Пароль в журнал не попадает: в строке старта только «задан / не задан».

## Инструмент

Один инструмент `sap_notes` с параметром `action`.

| action | Что делает | Параметры |
|---|---|---|
| `search` | Ноты и KBA по словам | `query`, `software_component` + `release` (только ноты для этого релиза), `support_package` (отбросить вошедшие в установленный пакет; `02` или `SAPK-10602INS4CORE`), `app_component` (префикс, например `FI-GL`), `limit` 1–50 |
| `read` | Нота: шапка, текст в markdown, действие, пакеты поддержки, предпосылки, ссылки, побочные эффекты, сводка инструкций | `number`, по желанию `software_component` + `release` — только предпосылки для этого релиза, `part` |
| `corrections` | Инструкция исправления для релиза: действует до пакета, объекты (TADIR), ноты-предпосылки, изменения кода в виде SNOTE | `number` + `software_component` + `release` либо `instruction_key`; `object` — код только подходящих объектов; `part` |
| `download` | Файл для SNOTE (`.SAR`, SNOTE → «Загрузить SAP Note») и/или PDF | `number`, `kind` = `sar` / `pdf` / `both` |
| `status` | Версия, режим и сервисы портала | — |

Обычный путь при ошибке в системе: `CVERS` системы (компонент, релиз, пакет
поддержки) → `search` по точному тексту сообщения или имени дампа → `read` →
`corrections` для своего релиза → проверка в системе: есть ли объекты, внесены
ли нота и её предпосылки (`CWBNTCUST`), стоит ли уже код. Фильтр по релизу
говорит лишь, что нота формально к нему относится.

## Установка (Claude Desktop)

Режиму browser нужен встроенный браузер Claude Desktop, режиму chrome — Chrome
или Edge.

**Расширение:** Настройки → Расширения → Расширенные настройки → Установить
расширение → `sap-notes.mcpb`.

**Бинарник:** положить `sap-notes.exe` в постоянное место и добавить в
`claude_desktop_config.json` (Настройки → Разработчик → Изменить конфиг):

```json
"sap-notes": {
  "command": "C:/Tools/MCP/sap-notes.exe"
}
```

Режим chrome — добавить `env`:

```json
"sap-notes": {
  "command": "C:/Tools/MCP/sap-notes.exe",
  "env": {
    "SAP_NOTES_MODE": "chrome",
    "SAP_USERNAME": "your.name@example.com",
    "SAP_PASSWORD": "..."
  }
}
```

| Переменная | По умолчанию |
|---|---|
| `SAP_NOTES_MODE` | `browser` |
| `SAP_USERNAME`, `SAP_PASSWORD` | — (без пароля — вход руками в окне) |
| `SAP_NOTES_DOWNLOAD_DIR` | `Downloads/SAP Notes` в домашней папке |
| `SAP_NOTES_PROFILE_DIR` | `sap-notes/browser-profile` в папке настроек пользователя |
| `SAP_NOTES_BROWSER` | Chrome, затем Edge — ищется сам |
| `SAP_NOTES_SHOW_BROWSER` | пусто; `1` — окно всегда видно |

Выйти из Claude Desktop через значок в трее и запустить снова. Проверка:
попросить Claude вызвать `sap_notes` с `action=status`; первая строка
`%APPDATA%\Claude\logs\mcp-server-sap-notes.log` показывает версию и режим.

## Сборка

Go 1.22+, внешних модулей нет.

```powershell
go test ./...
$env:CGO_ENABLED = "0"
go build -trimpath -ldflags "-s -w" -o dist\sap-notes.exe .
```

Все платформы и `.mcpb`: `bash build.sh`. Тесты гоняют скрипты браузера в Node
на записанных ответах портала; без Node эти тесты пропускаются.
`SAP_NOTES_E2E=1` добавляет сквозной тест режима chrome: настоящий Chrome
против поддельного портала на локальном HTTPS (вход в два шага, неверный
пароль, загрузка `.SAR`, PDF).

## Замечания

- Сервисы портала публично не документированы и могут поменяться.
- Поиск на стороне SAP медленный (10–20 с); у скрипта около 40 с.
- Строки кода длиннее 132 знаков портал переносит.
- Пользоваться в рамках вашего договора поддержки SAP.
